# Ball Mixing Game

Ball Mixing Game — это интерактивная физическая песочница, в которой цветные шарики перемещаются по экрану, сталкиваются и смешивают свои цвета.

## Как это работает

### Основная механика
- **Движение и коллизии**: Шарики хаотично движутся по экрану и отскакивают от границ окна.
- **Смешивание цветов**: При столкновении двух шариков их цвета усредняются, создавая новые оттенки. Для предотвращения быстрого превращения всех шариков в серый цвет, в процесс смешивания добавлена небольшая случайная вариативность.
- **Зона удаления**: В правом нижнем углу экрана находится красная зона. Любой шарик, попавший в неё, навсегда удаляется из игры.

### Управление
- **ЛКМ (Левая кнопка мыши)**: «Всосать» ближайший к курсору шарик в инвентарь.
- **ПКМ (Правая кнопка мыши)**: «Выплюнуть» шарик из инвентаря обратно на экран в позицию курсора.

## Запуск локально

### Зависимости
Для запуска игры вам понадобится Python 3.x и библиотека `pygame`.

1. **Установка зависимостей**:
   ```bash
   pip install pygame
   ```

2. **Запуск игры**:
   ```bash
   python gui.py
   ```

## Запуск через Docker

Игра может быть упакована в Docker-контейнер. Поскольку игра имеет графический интерфейс, для её отображения на хост-машине используется проброс X11.

### Сборка образа
```bash
docker build -t ball-mixing-game .
```

### Запуск контейнера
Для запуска в Linux (или macOS с XQuartz):
```bash
docker run -it --rm \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  ball-mixing-game
```

**Примечание для пользователей Windows/macOS**: Для работы графического окна из контейнера вам потребуется установленный X-сервер (например, VcXsrv для Windows или XQuartz для macOS) и соответствующая настройка прав доступа к X11 (например, выполнение `xhost +local:docker` в терминале).
